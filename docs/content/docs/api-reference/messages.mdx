---
title: Messages
---

`POST /v1/messages` is ModelPort's Anthropic-compatible client endpoint.

## Authentication

```text
Authorization: Bearer <MODELPORT_TOKEN>
```

## Request Body

Supported fields from the implemented schema:

- `model`
- `provider`
- `fallback_providers`
- `max_tokens`
- `system`
- `messages`
- `stream`
- `tools`
- `tool_choice`

## Example

```bash
curl http://127.0.0.1:13243/v1/messages \
  -H "Authorization: Bearer $MODELPORT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openrouter/google/gemini-2.5-flash",
    "max_tokens": 128,
    "messages": [
      { "role": "user", "content": "Hello from ModelPort." }
    ]
  }'
```

## Successful Response Shape

ModelPort returns an Anthropic-style assistant message:

```json
{
  "id": "chatcmpl_test_123",
  "type": "message",
  "role": "assistant",
  "model": "gpt-5.5",
  "content": [
    { "type": "text", "text": "Hello from OpenAI" }
  ],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 12,
    "output_tokens": 7
  }
}
```

## Notes

- Streaming is supported with Server-Sent Events.
- Provider selection is required unless it can be inferred from the model id.
- Anthropic-compatible upstream providers are not implemented yet; the working path today translates onto OpenAI-compatible upstream providers.
