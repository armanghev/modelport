---

<Callout type="warn" title="Placeholder">
There is no billing API in the current backend.
</Callout>

ModelPort currently tracks **estimated** cost based on request logs and pricing overrides. The implemented surfaces are:

- `GET /analytics/costs`
- `GET /admin/pricing`
- `POST /admin/pricing`
- `PATCH /admin/pricing/{pricing_id}`

This is cost estimation and pricing configuration, not provider billing reconciliation or invoice management.
