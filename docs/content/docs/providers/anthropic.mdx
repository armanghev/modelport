<Callout type="warn" title="Placeholder">
Anthropic is seeded in configuration and supported as a native `anthropic_compatible` upstream provider.
</Callout>

Use the Anthropic API root as the provider `base_url`, for example `https://api.anthropic.com`. ModelPort uses the native Anthropic `v1/messages` and `v1/models` surfaces for this provider type.
