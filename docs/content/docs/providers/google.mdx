---
title: Google
---

The seeded Google provider represents Gemini's OpenAI-compatible endpoint and is exposed under the provider id `gemini`.

## Default Seed

```yaml
gemini:
  type: "openai_compatible"
  display_name: "Gemini"
  base_url: "https://generativelanguage.googleapis.com/v1beta/openai"
```

## Model Routing

The following model forms are implemented:

- `models/gemini-2.5-flash`
- `gemini/models/gemini-2.5-flash`

ModelPort also has Gemini-native model metadata support for the dashboard and admin model directory.

## Credential Setup

```bash
GEMINI_API_KEY=...
```
