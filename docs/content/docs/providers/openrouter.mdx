---
title: OpenRouter
---

OpenRouter is implemented as an `openai_compatible` upstream provider and plays a central role in ModelPort's model-id inference.

## Default Seed

```yaml
openrouter:
  type: "openai_compatible"
  display_name: "OpenRouter"
  base_url: "https://openrouter.ai/api/v1"
```

## Supported Routing Patterns

These route to OpenRouter:

- `openrouter/auto`
- `openrouter/google/gemini-2.5-flash`
- `google/gemini-2.5-flash`
- `nvidia/nemotron-3.5-content-safety:free`

For provider-prefixed vendor models, ModelPort strips the leading `openrouter/` before sending the upstream request.

## Metadata and Pricing

ModelPort uses OpenRouter as a source for:

- model directory metadata
- pricing catalog enrichment
- provider dashboard model listings

## Credential Setup

```bash
OPENROUTER_API_KEY=...
```
