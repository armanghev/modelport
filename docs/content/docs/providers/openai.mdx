---
title: OpenAI
---

OpenAI is implemented as an `openai_compatible` upstream provider.

## Default Seed

```yaml
openai:
  type: "openai_compatible"
  display_name: "OpenAI"
  base_url: "https://api.openai.com/v1"
```

## Supported Paths

When selected, OpenAI can serve:

- `GET /v1/models`
- `POST /v1/chat/completions`
- `POST /v1/messages` through ModelPort's translation layer

## Credential Setup

Set:

```bash
OPENAI_API_KEY=...
```

Or create a database-backed provider credential through the admin API.
